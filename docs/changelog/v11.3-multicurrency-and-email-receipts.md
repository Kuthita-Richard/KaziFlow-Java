# v11.3 — Multi-Currency Support & Email Receipts

**Task:** Phase 10E, items 5–6/6.

## Multi-currency
- **Where:** new `src/main/java/com/kaziflow/services/CurrencyService.java`, `src/main/java/com/kaziflow/utils/KESFormatter.java`, `src/main/java/com/kaziflow/views/SettingsView.java`, `src/main/java/com/kaziflow/views/SalesView.java`
- **Design decision:** every stored amount stays in KES (the database's permanent base currency) — nothing is ever written to the DB in a converted currency. `CurrencyService` only converts KES → the chosen display currency (USD/EUR) at the moment of formatting, via an editable exchange rate. This keeps every existing calculation (VAT, totals, reports, loyalty points) untouched — only the label shown changes.
- `KESFormatter.format()`/`formatShort()` now route through `CurrencyService` (despite the class name, kept for backward compatibility with ~100 existing call sites). `formatNumber()` deliberately stays currency-agnostic since it's also used for plain quantities (stock counts, chart axis ticks).
- New Currency settings dialog (Settings → Currency): pick display currency, set "KES per 1 USD" / "KES per 1 EUR".
- Fixed 5 leftover hardcoded `"KES " + KESFormatter.formatNumber(...)` concatenations in `SalesView` (product price label, subtotal/vat/total/change labels) to route through the now currency-aware `format()`.

## Email receipts
- **Where:** new `src/main/java/com/kaziflow/services/EmailService.java`, `src/main/java/com/kaziflow/services/ReceiptPrinter.java`, `src/main/java/com/kaziflow/views/SettingsView.java`
- Implemented via raw SMTP over implicit TLS (port 465) using only `javax.net.ssl` — **no new Maven dependency**, since this sandbox's network allowlist doesn't cover Maven Central and a new dependency couldn't be reliably added or verified here.
- Works with any SMTP-over-SSL provider (Gmail app passwords, SendGrid, Mailgun) — `AUTH LOGIN`, base64 credentials.
- Added a "📧 Email" button to the receipt preview dialog (`sendEmailReceipt()`), and an SMTP settings dialog (Settings → Email Receipts) with a "Send Test Email" button.
