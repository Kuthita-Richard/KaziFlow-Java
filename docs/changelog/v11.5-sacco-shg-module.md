# v11.5 — SACCO / SHG Module (Phase 10A)

**Design decision confirmed via research:** real Kenyan SACCOs use **reducing-balance** loan interest, not flat/simple interest — flat rate is what predatory mobile lenders use. Switched from an earlier "simple interest for ease of build" default to reducing balance for credibility.

## New industry profiles
- **Where:** `src/main/java/com/kaziflow/modules/IndustryProfile.java`
- `SACCO` — Savings & Credit Co-operative. Module list: dashboard, sacco, employees, finance, reports, settings, help. Terminology: `customer` → `Member`.
- `SHG_SACCO` — Self-Help Group / Chama. Same but no `employees` module (informal groups typically have none) and a lighter module list.

## New module: members, loans, dividends, merry-go-round
- **Where:** new `src/main/java/com/kaziflow/dao/SaccoDAO.java`, new `src/main/java/com/kaziflow/views/SaccoView.java`, new `src/main/java/com/kaziflow/modules/core/SaccoModule.java`, `src/main/java/com/kaziflow/modules/ModuleRegistry.java`, `src/main/java/com/kaziflow/App.java`, `src/main/resources/i18n/messages_en.properties` + `messages_sw.properties`
- 7 new tables: `sacco_members`, `sacco_savings_transactions`, `sacco_loans`, `sacco_loan_repayments`, `sacco_dividends`, `sacco_mgr_groups`, `sacco_mgr_members`, `sacco_mgr_contributions`.
- **Loans (reducing balance):** `disburseLoan()` generates a full amortization schedule using the standard equal-installment formula `payment = P·r·(1+r)^n / ((1+r)^n − 1)`, recalculating interest each month on the declining principal. Last installment absorbs any rounding remainder so no stray balance is left. A loan must be `approved` before it can be disbursed — no skipping straight from `pending`.
- **Dividends:** `declareDividends(year, ratePercent)` pays out proportional to each active member's `share_capital`.
- **Merry-go-round:** rotating payout order via `payout_position`; `getCurrentPayoutRecipient()` computes whose turn it is as `((currentCycle − 1) % memberCount) + 1`; `advanceMgrCycle()` moves to the next round.
- `SaccoView` — 4 tabs: Members (register + record deposits/withdrawals), Loans (apply/approve/reject/disburse + repayment schedule with per-installment payment recording), Dividends (declare + history), Merry-Go-Round (create groups, assign members, check current payout).
