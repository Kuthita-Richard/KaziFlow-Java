# v11.26 — Reusable Password Show/Hide Toggle (`PasswordFieldUtils`)

**Task:** password eye-toggle, built as ONE reusable component (the `DialogUtils` pattern), applied everywhere a `PasswordField` exists. First of the four tasks queued after the permissions engine (v11.25).

## Component: `com.kaziflow.utils.PasswordFieldUtils`

- `withToggle(PasswordField)` → returns an `HBox` (field + eye button) to put in the layout instead of the bare field.
- The original `PasswordField` stays the source of truth: callers keep configuring it and reading `getText()` exactly as before. A plain-`TextField` mirror is bound to it (text both ways; prompt text, style, style classes, editable, disable, pref size, and `onAction` one way), and only one of the two is visible at a time.
- Icon: open eye = hidden ("click to show"); crossed eye = visible ("click to hide"). Drawn from JavaFX shapes (no emoji/font/SVG-path dependency). Tooltip follows state. The button is not focus-traversable, so Tab order is unchanged.
- Helpers for code that manipulates the field: `requestFocus(pf)` (focuses whichever input is showing — a hidden node can't take focus), `setRevealed(pf, bool)`, `isRevealed(pf)`. All are safe on a never-wrapped field.
