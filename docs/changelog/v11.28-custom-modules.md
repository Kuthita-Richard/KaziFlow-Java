# v11.28 — Custom modules: admin-built departments (engine + generated screen + builder)

An administrator can now add a department the product doesn't ship with (the Ambulance / Staff Transport example) without a developer, a code change or a redeploy. Design and evidence: `docs/design/custom-modules.md`.

## What was built (package `com.kaziflow.custom`)
- **Definitions:** `CustomModuleService` — modules → record types → fields (text, long text, whole/decimal number, money, date, date-time, yes/no, choice list, link to another record type, calculated). Immutable field keys; archive instead of drop; type and link target fixed once created; deleting refused while data exists (deactivate instead).
- **Records:** `CustomRecordService` — every value validated against its field (type, required, choice list, link target exists and is the right kind); soft delete; a record other records still link to can't be deleted; values-only search with `%`/`_` treated literally.
- **Formulas:** `FormulaEngine` — own parser, whitelisted functions (`ROUND MIN MAX ABS IF`, `SUMOF`/`COUNTOF` over child records), evaluated in Java; no scripting, no SQL string-building; divide-by-zero or a missing value gives an empty result, not an error.
- **Runtime screen:** `CustomModuleView` — one screen renders any module: a tab per record type, searchable list, totals for numeric columns, a generated add/edit form, buttons following the user's Create/Write/Delete access to that module.
- **Builder:** `CustomModuleBuilderView` (Settings → Custom Modules) — create/edit/deactivate/delete modules; add/rename/delete record types; add/edit/archive fields; formulas typed with readable names.
- **Wiring:** `CustomModule` / `CustomModuleLoader` (registered at startup and after builder saves), `ModuleRegistry.registerModule/unregisterModule`; admin-built modules appear in the Positions editor automatically (id `x_<key>`), default-deny until granted; hidden from System Modules toggles.

## Bugs found and fixed on the way
- **Transaction failure under load (real, affects v11.27):** `PermissionAdminService.guarded()` read before writing; in WAL mode that fails instantly with `SQLITE_BUSY_SNAPSHOT` when the async audit writer commits in between (the 5 s busy timeout doesn't apply). Now a bounded retry of the (fully rolled-back, idempotent) transaction; the permission seeder retries too.
- Search over raw JSON matched internal field keys (`_` matched everything) → search values only (`json_each`).
